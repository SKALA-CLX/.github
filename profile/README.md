## 팀 협업과 CI 안내

CLX 팀에서 함께 사용할 Git 작업 방식과 CI·배포 준비 현황을 정리합니다.

- [Git 협업 가이드](../docs/GIT_협업_가이드.md): 이슈, 브랜치, 커밋, PR과 리뷰 흐름
- [CI·배포 준비 가이드](../docs/CI_CD_가이드.md): 저장소별 검사, 이미지 게시 계획과 확인할 사항

이 문서는 팀이 검토하고 업데이트하는 기준 문서입니다. 문서에 적힌 팀 약속과 GitHub에서 실제로 강제되는 설정은 다를 수 있으므로 각 저장소의 PR과 설정을 함께 확인해 주세요.
